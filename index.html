Microsoft Azure Speech

Microsoft'un profesyonel ses hizmeti. Türkçe doğal sesler (Emel, Ahmet) ve iyi Türkçe konuşma tanıma. Ücretsiz katman: ayda 500.000 karakter seslendirme ve 5 saat konuşma tanıma; günde birkaç soru için fazlasıyla yeter.

  1. portal.azure.com'a Microsoft hesabınla gir. Hesabın yoksa ücretsiz Azure hesabı aç (kimlik doğrulaması için kart istenebilir; ücretsiz katmanda ücret alınmaz).
  2. "Speech service" oluştur: Bölge olarak West Europe, Fiyat katmanı olarak Free F0 seç.
  3. Oluşan kaynakta sol menüden Keys and Endpoint'e gir: KEY 1'i kopyalayıp aşağıya yapıştır; Location/Region'da yazanı bölge kutusuna yaz.
ElevenLabs en insansı ses

Duygulu, nefes alan, gerçek insana en yakın sesler. Ücretsiz plan: ayda 10.000 karakter (yaklaşık 30 cevap, yalnızca kişisel kullanım). Ücretli planlar ayda 6 $'dan başlar.

  1. elevenlabs.io'da hesap aç.
  2. API Keys sayfasında Create API Key ile anahtar oluştur, kopyalayıp aşağıya yapıştır.
  3. "Kaydet ve dene"ye bas; yukarıdaki Ses listesinden beğendiğin sesi seç.
API anahtarı nedir?

Bir servisin (Azure, ElevenLabs, OpenRouter gibi) seni tanıması için verdiği gizli bir şifredir. PDF Kalemi anahtarı yalnızca bu cihazda saklar ve yalnızca o servisle konuşurken kullanır; başka hiçbir yere göndermez. Anahtarını kimseyle paylaşma. Yanlışlıkla paylaşırsan servisin sayfasından silip yenisini oluşturabilirsin.
